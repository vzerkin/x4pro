# Commands:
#          A   - run all tests and exit
#          C   - clean log file, remove generated output files
#          #   - run example number #, where #:[0..26]
#          #-# - run examples by range of numbers, e.g. 1-5
#          L   - list examples
#          S   - statistics of the local EXFOR-database
#          V   - versions of system components
#          Q   - exit
