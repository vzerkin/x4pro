How to install MinGW-64
by V.Zerkin, 2026-02-23

0. Go to Web site:
	https://www.msys2.org/

1. Download and run installer:
	C:\Downloads> msys2-x86_64-20251213.exe
......

5. Now MSYS2 is ready for you and a terminal for the UCRT64 environment will launch.
	$ UCRT64
	$ exit

6. Configure
	> cd C:\msys64
	C:\msys64> autorebase.bat
	> set path=G:\msys64\mingw64\bin;%path%
	> set path=G:\msys64\ucrt64\bin;%path%
	> set path=G:\msys64\usr\bin;%path%

7. See available packages:
	https://packages.msys2.org/package/

8. Install C-compiler
	> pacman -S mingw-w64-ucrt-x86_64-gcc
	> gcc --version
	  gcc (Rev8, Built by MSYS2 project) 15.2.0
	  Copyright (C) 2025 Free Software Foundation, Inc.
	  This is free software; see the source for copying conditions.  There is NO
	  warranty; not even for MERCHANTABILITY or FITNESS FOR A PARTICULAR PURPOSE.

9. Install Fortran-compiler
	> pacman -S mingw-w64-x86_64-gcc-fortran
	> gfortran --version
	  GNU Fortran (Rev8, Built by MSYS2 project) 15.2.0
	  Copyright (C) 2025 Free Software Foundation, Inc.
	  This is free software; see the source for copying conditions.  There is NO
	  warranty; not even for MERCHANTABILITY or FITNESS FOR A PARTICULAR PURPOSE.

10. Install additional utilities: zip, unzip, dialog
	> pacman -S zip
	> pacman -S unzip
	> pacman -S dialog
	> dialog --version
	  Version: 1.3-20250817

11. After installing MSYS2 it will update itself via pacman, see the update guide for more information.
	https://www.msys2.org/docs/updating/
