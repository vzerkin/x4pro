Examples of search by SQL commands in X4Pro/SQLite:
  1. Find zero values coded under headings PARITY, ERR-T, DATA-ERR
  2. Text plotting DATA from a Dataset

______________________________________________________________________

I.  System environment:
  1. check python3 (install if you don't have it)
              $ python  --version
           or $ python3 --version
  2. Install sqlite3
     Windows: Download from https://www.sqlite.org/download.html
              file (example): sqlite-tools-win-x64-3470200.zip,
                              unzip (for example, by "7z")
     Linux:   $ sudo apt-get install sqlite3
           or $ snap install sqlite3
     MacOS:   $ brew install sqlite3

______________________________________________________________________

II. Run programs on X4Pro database

    $ python -B err-t.py    >err-t.tto
    $ python -B data-err.py >data-err.tto
    $ python -B exec1sql.py EN-le0.sql  EN-le0py >EN-le0py.tto
    $ python -B exec1sql.py PTY-eq0.sql PTY-eq0  >PTY-eq0.tto

    $ sqlite3 -header -box x4sqlite1.db <sql3.sql   >sql3.txt
    $ sqlite3 -header -box x4sqlite1.db <EN-le0.sql >EN-le0.txt
    $ sqlite3 -header -csv x4sqlite1.db <EN-le0.sql >EN-le0.csv
